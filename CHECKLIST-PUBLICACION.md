# Checklist de publicación

## Contenido

- [ ] No quedan nombres, eventos ni documentos de ejemplo.
- [ ] Todas las fechas incluyen el año cuando corresponde.
- [ ] Los estados de inscripción coinciden con la realidad.
- [ ] Los documentos muestran versión o fecha de actualización.
- [ ] Dirección, horario, email y WhatsApp fueron confirmados.

## Enlaces

- [ ] `python tools/check_site.py` finaliza correctamente.
- [ ] Todos los enlaces de Drive abren sin una cuenta personal.
- [ ] WhatsApp, email y teléfono abren la aplicación correcta.
- [ ] El 404 permite volver al Inicio.

## Presentación

- [ ] Inicio revisado en móvil y escritorio.
- [ ] Capacitaciones legibles a 390 px.
- [ ] Menú móvil abre, cierra y responde a Escape.
- [ ] Navegación completa posible con teclado.
- [ ] Imágenes autorizadas, optimizadas y con texto alternativo.

## GitHub Pages

- [ ] `index.html` y `.nojekyll` están en la raíz del repositorio.
- [ ] No se subieron ZIP ni exportaciones duplicadas.
- [ ] Pages publica desde `main` y `/ (root)`.
- [ ] HTTPS está forzado.
- [ ] Se configuraron dominio, `canonical`, `og:url`, `og:image` y favicon.
- [ ] Se actualizó `robots.txt` con la URL pública definitiva.
